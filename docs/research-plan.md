# 第一课调研计划

我们想弄清楚，在决定买一件衣服时，人会怎样想起自己已经有的衣物，以及这次花力气做的选择会不会在收货后继续有用。以下是执行计划，访谈完成后另交有证据的调研报告。

以第二次课为 T。组长协调进度。下表的执行岗位由成员在调研 Issue 认领，完成后附上执行人与证据链接。[调研 Issue](https://github.com/MXH814/DressWell/issues/3)

[十条课前用户故事初稿](story-drafts.md) 供访谈后逐条核实。

若实际课间少于四天，组长按可用时间并行安排访谈和竞品任务，并记录调整。受访者可跳过任何问题；仓库只收录去标识化记录。

## 访谈问题

1. 最近一次看中一件衣服是在什么地方？从心动到决定，接下来实际做了什么？
2. 当时你想到了衣柜里的哪件衣服？你怎样判断它们穿在一起好不好看？
3. 如果看过不同店铺，你怎么判断是同一款？尺码、运费、优惠或者退换条件，哪项改变了你的选择？
4. 最近一次买回家却很少穿的衣服是什么？第一次决定不穿它的那天，发生了什么？
5. 请回想昨天出门前最后换掉的一件衣服。当时为什么换？换成了什么？
6. 哪一步你用现有办法已经做得很顺？有没有哪一步，你宁愿自己决定？
7. 如果要把衣物信息保留下来，你已经在用什么办法？哪些资料你不愿上传？

## 用同一个任务检验竞品

准备一张待购外套照片、一条商品链接、目标尺码、三件已有衣物的照片。依次尝试找到候选款、核对同款与报价条件、用已有衣物试搭、模拟确认留用、一周后按场合重新配一套。记录每步是否完成、耗时、需重新输入的字段、证据位置。碰到登录、地区、付费或数据限制时照实记录，保留“未验证”。无需实际下单。

## 调研后的证据怎么写

一份纪要对应一次真实访谈，写明匿名编号、日期、方式、访谈和记录成员、经同意记下的原话、观察到的行为及反例。每条调研发现链接到纪要或竞品任务记录，注明样本局限，再由团队决定采纳、推迟或放弃什么。报告经独立评审后走 PR。
